AnimeVault v1.3.3 — подключение облачной синхронизации

1. Откройте Supabase Dashboard -> SQL Editor -> New query.
2. Скопируйте весь файл SUPABASE_SETUP.sql, вставьте и нажмите Run.
3. В Authentication -> Providers -> Email включите Email provider.
4. При желании для первого теста можно отключить Confirm email в Authentication -> Settings -> Email Auth. Если подтверждение включено, после регистрации откройте письмо и подтвердите адрес.
5. В Authentication -> URL Configuration укажите Site URL — фактический HTTPS-адрес AnimeVault. Добавьте этот же адрес в Redirect URLs. Для локального теста добавьте http://localhost:8000/**.
6. Разместите файлы приложения на HTTPS-хостинге (или запустите start.bat на ПК для localhost).
7. Откройте AnimeVault -> Облако -> Создать аккаунт. Используйте один и тот же аккаунт на ПК и телефоне.

В приложении уже указан Project URL и Publishable key вашего Supabase-проекта. Secret key/service_role в приложение НЕ добавлять и никому не отправлять.

Как работает синхронизация:
- IndexedDB остаётся локальной базой, приложение продолжает работать офлайн.
- Первая синхронизация отправляет существующие записи в облако.
- Последующие синхронизации передают изменения и загрузят их на других устройствах.
- Удаления передаются как tombstone (мягкое удаление), чтобы запись не воскресала на другом устройстве.
- Синхронизация запускается при входе, восстановлении сети, возвращении во вкладку и далее примерно раз в минуту, пока приложение открыто.
- При конфликте применяется правило «последнее изменение по времени побеждает».
- Выход из аккаунта не удаляет локальную библиотеку.

Важно: сначала выполните SQL. Пока таблица и RLS-политики не созданы, синхронизация закономерно не заработает.
