# AnimeVault PWA

Полноценный адаптивный трекер аниме с локальной базой IndexedDB, импортом/экспортом CSV и офлайн-режимом.

## Что внутри

- `index.html`, `app.js` — приложение.
- `manifest.json`, `sw.js` — установка как PWA и кэширование оболочки.
- `icon-192.png`, `icon-512.png` — иконки приложения.
- `AnimeVault_Import_1042.csv` — очищенная стартовая база из вашего Anixart CSV.
- `start.bat` — запуск локального сервера на Windows.
- Режимы отображения: карточки и компактный список.
- Фильтры: статус, жанр, формат, год, наличие постера и метаданных.
- Статистика с диаграммами и расчётом просмотренных серий/часов.
- Массовое получение метаданных через публичный AniList GraphQL API.

## Первый запуск

1. Распакуйте весь архив в одну папку.
2. На Windows дважды нажмите `start.bat` (нужен установленный Python).
3. Откроется `http://localhost:8000`.
4. При первом запуске пустая библиотека автоматически заполнится 1 042 записями из `AnimeVault_Import_1042.csv`.
5. Кнопка «Установить приложение» отображается в шапке. Если браузер не предоставляет встроенный запрос установки, используйте меню браузера → «Установить приложение» / «Добавить на главный экран».

Важно: не открывайте `index.html` двойным щелчком через `file://`. Service Worker и установка PWA требуют `https://` или `localhost`.

## Установка на смартфон

Чтобы установить приложение на смартфон, разместите содержимое папки на HTTPS-хостинге (например, собственном сайте или статическом хостинге), откройте адрес в мобильном браузере и выберите «Добавить на главный экран» / «Установить приложение».

## Импорт и повторный импорт

- CSV можно импортировать кнопкой «Импорт».
- При совпадении названия запись обновляется, а не дублируется.
- Пустые поля постера и ссылки не затирают уже сохранённые вручную значения.
- Экспорт CSV включает названия, альтернативные названия, избранное, статус, номер серии, ссылку на просмотр и ссылку на постер.
- «Бэкап JSON» сохраняет полную копию записей.

Стартовая база содержит 1 042 записи. Несколько некорректно экранированных строк исходного CSV были нормализованы, сохранив названия и статусы.

## Автономная работа

После первого успешного открытия Service Worker кэширует приложение и библиотеку Dexie. Сама библиотека аниме хранится в IndexedDB браузера и доступна без сети. Получение описаний, числа серий, длительности, жанров, рейтинга и постеров через публичный AniList API требует интернет-соединения. Откройте страницу «Обновление» и нажмите «Обновить только непроверенные» для обработки записей, для которых поиск ещё не выполнялся. Из-за ограничений API обработка большой библиотеки выполняется постепенно; на 1 000 записей может уйти около 40 минут. Не закрывайте приложение до завершения. Временные ограничения API могут увеличить срок.

## Важное о данных

База хранится локально в профиле браузера/установленного PWA. Для переноса на другое устройство используйте «Экспорт CSV» или «Бэкап JSON». Очистка данных сайта браузером может удалить локальную базу.

## AniList и статистика

AniList — открытый GraphQL API без ключа для чтения публичных данных. Приложение сохраняет найденные описание, общее число серий, длительность серии, жанры, формат, год, оценку и постер в локальной базе. Массовое обновление доступно на отдельной странице «Обновление». Найденные записи и записи с завершённой попыткой поиска автоматически пропускаются. Ручной постер не заменяется данными API. Статистика считает завершённые аниме по полному числу серий, а для остальных статусов — по сохранённому текущему прогрессу. Часы являются оценкой: число просмотренных серий × средняя длительность серии из AniList. Для доступа к API требуется интернет; библиотека и статистика после загрузки данных доступны офлайн.

### Центр обновления данных — v1.3.2

- Добавлена отдельная страница «Обновление данных» в меню, верхней навигации и мобильной нижней панели.
- На странице есть запуск обработки, остановка, общий прогресс, счётчики результатов и журнал по каждой записи.
- Журнал сохраняется локально на устройстве и доступен после перезапуска приложения.
- Записи с AniList ID, сохранённой датой обновления или отметкой завершённой попытки не отправляются повторно. Успешный поиск и результат «не найдено» фиксируются в IndexedDB.

- Запросы идут по одному с интервалом, с тайм-аутом 25 секунд и остановкой очереди при потере соединения — это снижает риск сбоев на мобильных устройствах.

## Облачная синхронизация и постеры (v1.3.4)

В сборке работает синхронизация через Supabase Auth (GitHub OAuth или email + пароль), таблицу `public.animevault_records` с RLS и Supabase Storage bucket `animevault-posters`. При синхронизации приложение переносит доступные для загрузки постеры в Storage и сохраняет публичный URL облачной копии в записи. Инструкция и повторно запускаемый SQL находятся в `SUPABASE_SETUP_RU.txt` и `SUPABASE_SETUP.sql`.

IndexedDB остаётся локальной базой для офлайн-работы. Используйте один и тот же аккаунт AnimeVault на всех устройствах. Не добавляйте Secret/service_role key в клиентский код.


### Облачные постеры

- Выполните обновлённый `SUPABASE_SETUP.sql` в SQL Editor, чтобы создать bucket `animevault-posters` и политики загрузки в личную папку пользователя.
- Откройте AnimeVault онлайн и нажмите «Синхронизировать сейчас». Приложение загружает постеры партиями по три, показывает ход обработки и использует облачный URL в приоритете.
- Исходный `posterUrl` сохраняется как резерв. Если внешний хост запрещает CORS, браузер не сможет скопировать конкретное изображение; такая карточка продолжит использовать исходный URL.
- Bucket публичен для чтения изображений по URL; операции записи ограничены папкой текущего пользователя. Не используйте bucket для личных изображений.
