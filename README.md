# AnimeVault PWA

Полноценный адаптивный трекер аниме с локальной базой IndexedDB, импортом/экспортом CSV и офлайн-режимом.

## Что внутри

- `index.html`, `app.js` — приложение.
- `manifest.json`, `sw.js` — установка как PWA и кэширование оболочки.
- `icon-192.png`, `icon-512.png` — иконки приложения.
- `AnimeVault_Import_1042.csv` — очищенная стартовая база из вашего Anixart CSV.
- `start.bat` — запуск локального сервера на Windows.

## Первый запуск

1. Распакуйте весь архив в одну папку.
2. На Windows дважды нажмите `start.bat` (нужен установленный Python).
3. Откроется `http://localhost:8000`.
4. При первом запуске пустая библиотека автоматически заполнится 1 042 записями из `AnimeVault_Import_1042.csv`.
5. Для установки на ПК нажмите значок установки в адресной строке браузера (если он доступен).

Важно: не открывайте `index.html` двойным щелчком через `file://`. Service Worker и установка PWA требуют `https://` или `localhost`.

## Установка на смартфон

Чтобы установить приложение на смартфон, разместите содержимое папки на HTTPS-хостинге (например, собственном сайте или статическом хостинге), откройте адрес в мобильном браузере и выберите «Добавить на главный экран» / «Установить приложение».

## Импорт и повторный импорт

- CSV можно импортировать кнопкой «Импорт».
- При совпадении названия запись обновляется, а не дублируется.
- Пустые поля постера и ссылки не затирают уже сохранённые вручную значения.
- Экспорт CSV включает названия, альтернативные названия, избранное, статус, номер серии, ссылку на просмотр и ссылку на постер.
- «Бэкап JSON» сохраняет полную копию записей.

Стартовая база содержит 1 042 записи. Несколько некорректно экранированных строк исходного CSV были нормализованы, сохранив названия и статусы.

## Автономная работа

После первого успешного открытия Service Worker кэширует приложение и библиотеку Dexie. Сама библиотека аниме хранится в IndexedDB браузера и доступна без сети. Поиск постеров через Shikimori требует интернет-соединения.

## Важное о данных

База хранится локально в профиле браузера/установленного PWA. Для переноса на другое устройство используйте «Экспорт CSV» или «Бэкап JSON». Очистка данных сайта браузером может удалить локальную базу.
